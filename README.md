# 짤만들기

설치 없이 동작하는 정적 이미지 편집 사이트입니다. `python -m http.server 5173 --directory dist`로 실행한 뒤 `http://localhost:5173`에서 사용합니다. 이미지 저장 기능은 HTTP(S) 주소에서 사용해 주세요.

- JPG/PNG/WebP/GIF 불러오기, 여러 이미지 전환
- 문구 8개까지 추가, 글꼴·색·크기·테두리 편집 및 드래그 위치 이동
- 흑백·레트로·채도 효과와 집중선
- PNG 다운로드 및 모바일 저장용 결과 이미지

이미지는 서버로 전송하지 않고 IndexedDB에 원본 파일을 저장합니다. 파일당 최대 20MB, 최대 12장을 보관하며 개별 삭제할 수 있습니다. 새로고침과 작업 초기화 후에도 이미지 목록은 유지됩니다. 문구·효과는 저장하지 않습니다. 같은 브라우저와 사이트 주소에서만 복원되며, 브라우저 데이터 삭제나 저장 공간 정리 시 이미지가 사라질 수 있습니다. 비공개 탐색에서는 영구 보관을 기대하지 마세요.

출력 이미지의 긴 변은 최대 1600px로 줄이며 GIF는 정지 이미지로 처리합니다. 기본 배경은 네 가지 색상이며 별도의 캐릭터 이미지는 포함하지 않습니다.

## GitHub Pages 배포

현재 운영 주소는 Sites에서 제공됩니다. GitHub Pages에서도 서버 없이 사용할 수 있습니다.

1. 이 프로젝트를 원하는 GitHub 저장소의 `main` 브랜치에 올립니다.
2. 저장소의 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 선택합니다.
3. **Actions → Deploy GitHub Pages → Run workflow**를 실행합니다. 이후 `main`에 올린 변경 사항은 자동 배포됩니다.

`.github/workflows/pages.yml`은 `dist` 폴더만 게시합니다. 실제 GitHub 저장소 연결과 배포는 아직 수행하지 않았습니다. Pages 주소로 옮기면 기존 Sites 주소에 저장했던 이미지는 자동 이전되지 않으므로 다시 업로드해야 합니다.
